# Architecture 文档入口

本目录记录已批准的系统架构、服务边界、数据流、运行拓扑和接口边界。新增内容必须引用对应 feature spec/plan，并保持终端→边端→云端链路及 `assetId`、`terminalId`、`edgeId`、`eventId` 语义独立。

本 bootstrap 只建立入口，不代表完整设备诊断架构或业务功能已经实现。长期决策请同步记录到 [`../adr/README.md`](../adr/README.md)，操作步骤记录到 [`../runbooks/README.md`](../runbooks/README.md)。

当前无业务行为骨架见 [`001-cloud-edge-diagnostics-skeleton.md`](001-cloud-edge-diagnostics-skeleton.md)。
