# ADR 文档入口

本目录记录需要长期保留的架构决策、备选方案、影响范围、状态和决策人。ADR 必须关联对应 `spec.md`/`plan.md`，不得用未确认的决策直接扩大生产实现范围。

治理 bootstrap 的约束见 [`../../.specify/memory/constitution.md`](../../.specify/memory/constitution.md)；业务存储、安全和可靠性基线见 [`001-cloud-edge-storage-security-reliability.md`](001-cloud-edge-storage-security-reliability.md)。
