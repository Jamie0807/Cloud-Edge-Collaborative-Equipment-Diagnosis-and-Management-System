# Team Skills

Repository-local skills for the cloud-edge device diagnostics management system. They are intentionally narrow: they apply the project's service boundaries, identity-field contract, validation evidence, and isolated-worktree rules without duplicating general agent policy.

| Skill                     | Use it for                                                                            |
| ------------------------- | ------------------------------------------------------------------------------------- |
| `project-bootstrap`       | Establishing or diagnosing a runnable local path without feature changes.             |
| `spec-driven-development` | Converting a business request into traceable feature artifacts before implementation. |
| `tdd-quality-gates`       | Implementing observable behavior with RED/GREEN evidence and project gates.           |
| `parallel-worktrees`      | Assigning independent tasks to isolated worktrees with disjoint write sets.           |
| `review-and-verify`       | Reviewing changes and reporting only evidence-backed completion status.               |

Each skill is discovered from its `SKILL.md` YAML description. Read the relevant skill before starting the matching work; repository-wide policy remains in `AGENTS.md`.
